### Proyectos destacados

#### Sistema Web de Gestión de Órdenes de Producción

Aplicación web empresarial desarrollada para Multigráfica Burgos E.I.R.L., orientada a centralizar y optimizar la gestión de órdenes de trabajo y procesos productivos.

**Funcionalidades principales:**
- Administración y seguimiento de órdenes de producción.
- Gestión de usuarios y autenticación.
- Control de estados del proceso productivo.
- Registro y seguimiento de actividades.

**Tecnologías:** React, JavaScript, Vite, Python, FastAPI y SQLAlchemy.

[Frontend](https://github.com/BurBear/MultiBurV1-frontend) · [Backend](https://github.com/BurBear/MultiBurV1-back)

#### Página Web Corporativa — Multigráfica Burgos

Desarrollo de un sitio web corporativo responsive para presentar servicios de impresión, productos gráficos y facilitar solicitudes de cotización.

**Tecnologías:** HTML5, CSS3 y JavaScript.

[Repositorio](https://github.com/BurBear/WEB-Multigrafica-Burgos-E.I.R.L.) · [Sitio web](https://www.multigraficaburgos.pe/)
